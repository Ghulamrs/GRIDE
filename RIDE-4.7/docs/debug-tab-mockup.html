Call Stack, how to read it

The top row (highlighted) is where the program is stopped now. Each row below is the function that called the one above it, at the line where the call is written: main, line 31, called countPrimes; countPrimes, line 24, called isPrime.

Clicking a frame

Clicking countPrimes opens line 24 in the editor and fills Locals with countPrimes' own variables (limit, found). Clicking the top row goes back to where the program stopped.

Values and addresses

A value shown in colour changed since the last stop (here d went from 2 to 3). An expression watch such as n % d has no address, shown as "-". For Shalimar, values and addresses come once its compiler records where each variable lives.

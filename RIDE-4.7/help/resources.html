Three languages · four targets · one editor on Windows, macOS and Linux

The editor

The window RIDE.exe · RIDE 5.17.app

Menus, the project tree, editor tabs, and the Console / Debug / Assembly panel (Errors / Progress / Output on macOS). Windows: bin\RIDE.exe, Start menu RIDE 5.17. macOS: RIDE 5.17 in Applications. Linux has no window.

The console editor RIDEConsole.exe · ride

The same editor in a terminal, with the mouse. Windows: bin\RIDEConsole.exe, Start menu RIDE 5.17 (console). macOS and Linux: ride or ride-5.17. Builds without a screen: ride <project> --build or --run.

Every compiler ends a good compile by naming what it made, by its full path, then <compiler>: compilation completed successfully - 0 errors. --version prints each one's version; Help ▸ About lists them all.

Headers and libraries

include 50 headers

cpp11's C++ library — <string>, <vector>, <map>, <iostream>, <algorithm>… — and the C headers they wrap.

lib 16 headers

c90's C library headers — stdio.h, stdlib.h, string.h, math.h…

bin/lib runtimes

Shalimar's run-time library for each target: shmrt-x86_64-windows.lib (and -debug), shmrt-tms6747 as assembly.

Right-click an #include line in the editor to open the header: it is looked for beside the file, in the project and its include paths, the shared ones, then include and lib.

GRIDE User Guide

C90 · C++11 · Shalimar — Windows · Linux · macOS · TMS320C6747

1. Getting started

  1. File > New > Project (Ctrl+Shift+N): choose a language, a template, a name, a location and the targets.
  2. GRIDE creates Name\Name.pro with src\, inc\ and lib\ folders, plus a workspace Name.grws.
  3. Choose Config and Target on the toolbar, then press F7 to build.

Before the first build, set the tool paths in Tools > Options > Toolchains. Tools > Toolchain Check shows what is installed.

2. The window

To float a pane, use the button on its title bar or double-click its tab. Close the floating window to dock the pane back. Window > Reset Window Layout restores the default layout.

3. Projects and workspaces

FileContents
.proOne project. Paths are relative to the .pro file, e.g. "src/kalman.c".
.grwsWorkspace: its projects, the startup project, the active Config and Target, and breakpoints.
gride.settings.jsonIDE settings, in %APPDATA%\GRIDE or next to GRIDE.exe (portable).

Code Composer Studio 7.4 projects can be opened with File > Open > CCS 7.4 Project, or added to a workspace. GRIDE reads .project, .cproject and .ccsproject and never writes to them. Their builds go into the project's .gride\ folder.

4. Building

Each step is a command template with macros such as $(Compiler), $(Source), $(AsmFile), $(ObjFile), $(Objects) and $(Output):

source → compile → .asm → assemble → .obj → link → program (.exe / .out)

  • Errors in MSVC, TI or GNU format appear in the Error List. Double-click one to jump to the line.
  • Build > Batch Build builds several Project · Config · Target combinations in one run.
  • Project > Properties (Alt+F7) edits defines, include dirs, optimisation, libraries and the linker .cmd file for each Config and Target.

5. Debugging

F9 toggles a breakpoint (or click the gutter). F5 builds and starts. Then:

  • F10 steps over, F11 steps into, Shift+F11 steps out.
  • Ctrl+F10 runs to the cursor; Shift+F5 stops.

Version 1.0 uses a placeholder debugger that simulates execution, so the whole debug UI works now. It will be replaced by the VM6747 / native debugger.

6. C ↔ Shalimar conversion

Use Tools > Convert (Ctrl+Alt+S for C → Shalimar, Ctrl+Alt+H for Shalimar → C). Set the converter paths in Tools > Options > Converters. GRIDE can add the result to the project and open it.
